# 📱 AI信息雷达 · 手机版（Android APK）

**离线优先的独立 App**：打开就能看日报，不需要输入网址、不依赖网络。
日报数据直接打包进 APK，电脑连得上时点「同步」拉取最新一期。

> ⚠️ **便携版提示**：本便携包只含手机版源码和 APK 成品，**未包含** Android 构建工具链（`toolchain/` 约 460MB）。
> 日常使用直接用 `dist/ai-radar.apk` 即可；要重新打包最新日报，请在完整版项目
> 在 Android 项目目录中运行 `build.bat`，并按本机环境准备构建工具链。

## 文件

| 文件 | 说明 |
|---|---|
| `dist/ai-radar.apk` | **手机安装包**（直接传到手机安装，v2/v3 已签名） |
| `bundle_reports.py` | 把 `../data/daily/` 的日报渲染打包进 `assets/`（构建时自动执行） |
| `build.bat` | 一键重新打包脚本（含打包日报步骤） |
| `make_icon.py` | 重新生成启动图标 |
| `toolchain/` | Android 构建工具（build-tools 34 + android.jar + JDK 17） |
| `java/` `res/` `assets/` `AndroidManifest.xml` | 应用源码与离线数据 |

## 手机安装

1. 把 `dist/ai-radar.apk` 传到手机（微信 / QQ / 数据线 / 网盘均可）
2. 手机上点击 APK 安装（提示"未知来源"时允许该来源即可）
3. 打开「AI信息雷达」，**直接就能看**打包好的全部日报
4. 未读日报带红点 ●，A 级事件显示徽章；点击进入全文，底部可翻上一篇/下一篇

## 同步最新日报（可选）

手机与电脑连**同一个 Wi-Fi**，App 内点右上角「同步」即可：

- 电脑端需保持运行：`start.bat`（或 `python src/app.py`）
- 示例同步地址 `http://192.168.1.100:8899`（请在 App 设置中修改为电脑实际局域网 IP）
- 同步成功会显示"已同步电脑 · N 期日报"；连不上则自动用本地日报，**不会报错卡住**

### 地址变了怎么办（设置）

电脑 IP 由路由器动态分配，重启路由器后可能变化。App 右上角「设置」里改一次即可：
1. 电脑上执行 `ipconfig`，找到 Wi-Fi 网卡的 IPv4 地址（如 `192.168.1.100`）
2. App「设置」→ 填入 `http://新IP:8899` → 保存

要彻底固定，可在路由器后台给电脑绑定 MAC（分配固定 IP）。

### 已读/未读

手机端已读状态存在手机本地；连上电脑同步时，会与电脑端状态双向合并——
手机上已读的日报，电脑浏览器也会显示已读（反之亦然）。

## 常见问题

### 断网 / 电脑关机能看到吗？
能。所有已打包和已同步过的日报都存在手机里，**离线可读**。只有"同步新日报"才需要电脑在线。

### 打开日报显示"手机上还没有这期"
该期只存在于电脑上，还没同步到手机。连同一 Wi-Fi 点「同步」后再打开即可。

### 同步总是不成功
- 确认电脑端服务在运行（`netstat -ano | findstr 8899` 能看到 LISTENING）
- 确认手机和电脑连的是**同一个 Wi-Fi**
- 确认地址带了端口 `:8899`，且在 App「设置」里与 `ipconfig` 查到的一致
- 首次被 Windows 防火墙拦截过的话，已放行规则 "AI Radar 8899"，一般无需再操作

## 重新打包

改完源码或想重新打包最新日报后，双击 `build.bat`（或命令行运行），产物输出到 `dist/ai-radar.apk`。
`build.bat` 会先自动运行 `bundle_reports.py`，把当前 `data/daily/` 里所有日报重新打包进 APK。
签名密钥 `release.jks` 已生成，后续打包自动复用——**请勿删除**，否则旧版本无法覆盖安装。
